# highlight-protocol

Build-time syntax highlighting for [cl-stack](https://github.com/egao1980/cl-stack): lexers turn source text into `(class . text)` tokens whose concatenation is exactly the input, an HTML renderer emits `<span class="hl-…">` with escaped text, and a default stylesheet (css-protocol, light and dark) colours the classes.

**Status:** planned (0.1.0). Brief: [cl-stack/docs/capabilities/highlight.md](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/highlight.md).
